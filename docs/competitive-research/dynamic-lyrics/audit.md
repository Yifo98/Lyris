# 灵动歌词黑盒审计

测试日期：2026-07-22。应用版本以本机当日安装版本为准。方法仅限用户可见 UI，不逆向二进制、不抓包、不访问私有缓存。

## 当前授权状态下的 Level A 观察

| 场景 | 观察 | 证据边界 |
| --- | --- | --- |
| 启动与识曲 | 打开后能显示当时 Spotify 曲目的标题、艺人、时长和封面 | 只能证明当前已授权环境 |
| 歌词 | 显示完整双语同步歌词，并提供搜索、翻译入口 | 未证明具体歌词来源或内部匹配算法 |
| 播放控制 | UI 有上一首、播放/暂停、下一首、收藏入口 | 未操作收藏，避免改变账号状态 |
| 校时 | 更多菜单提供歌词延迟 | 未记录其内部 offset 符号或持久化格式 |
| 展示 | 有模糊、字号、对齐、悬停控制、暂停自动隐藏、显示翻译等选项 | 仅用于能力比较，不复制布局或视觉表达 |
| 缓存 | 设置称可清除“自动获取歌词缓存”，且不清除手动上传 | 这是 UI 文案事实，不代表已检查磁盘实现 |
| 翻译 | 可选择目标翻译语言、繁体中文等 | 未验证翻译提供商、计费或数据流 |
| 授权状态 | “Spotify 授权状态”检查返回正常 | 当前安装已经授权 |

## 尚未完成的必要场景

| 场景 | 状态 | 原因 / 安全做法 |
| --- | --- | --- |
| 完全未授权启动 | 待 Level A | 当前安装已有 Spotify 授权；不能未经同意撤销用户授权。应使用隔离的新 macOS 用户/干净安装，或由用户主动断开后再测。 |
| Spotify 未运行 | 待 Level A | 本轮未终止用户正在使用的 Spotify。 |
| 网络中断 | 待 Level A | 不在用户主会话中擅自改网络。可后续用受控网络条件测试。 |
| 快速切歌 A→B→A | 待 Level A | 需要录制日志与视觉结果，且避免泄露收听记录。 |
| 同曲外部收藏变化 | 待 Level A | 会改变 Spotify 账号库，需用户确认测试曲目。 |
| 注销/重新授权恢复 | 待 Level A | 属于账号状态变化，必须由用户主导。 |

## 可借鉴与不可借鉴

可借鉴的是产品原则：启动即给核心歌词体验、授权状态可见、手动歌词不被自动缓存清理误删、展示选项即时预览。

不可借鉴的是具体胶囊/设置布局、品牌、图标、文案、歌词内容和任何未公开内部接口。Lyris 的默认模式还要更进一步：在没有 Spotify OAuth 时仍可通过公开 macOS 自动化提供本机曲目、控制和歌词，而需要账户能力时再升级授权。
