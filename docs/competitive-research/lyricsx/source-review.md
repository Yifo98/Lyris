## 结论先行

在上述固定提交的 **macOS 基础播放与歌词路径** 中，没有证据表明用户必须填写 Spotify Client Secret：

- macOS Spotify 播放器通过 ScriptingBridge/Apple Events 对本机 Spotify 应用读取曲目、状态和位置，并发送播放命令；构造路径没有 OAuth 参数（[Scriptable.swift L31-L49](https://github.com/MxIris-LyricsX-Project/MusicPlayer/blob/ced0ac74f3dd2d364743581e66404af0e35d37e7/Sources/MusicPlayer/Players/Scriptable.swift#L31-L49)、[LXPlayerSpotify.m L16-L55](https://github.com/MxIris-LyricsX-Project/MusicPlayer/blob/ced0ac74f3dd2d364743581e66404af0e35d37e7/Sources/LXMusicPlayer/Players/LXPlayerSpotify.m#L16-L55)）。
- LyricsX 默认歌词管理器只实例化无需认证的来源；可选 Musixmatch token 另行加入（[AppController.swift L71-L87](https://github.com/MxIris-LyricsX-Project/LyricsX/blob/e84963a6346b9a99dfdcaf082908f12247f1637b/LyricsX/Component/AppController.swift#L71-L87)、[Service.swift L23-L49](https://github.com/MxIris-LyricsX-Project/LyricsKit/blob/6f071990d0c9c6f48d29284db805990bffb912ed/Sources/LyricsService/Provider/Service.swift#L23-L49)）。
- LyricsKit 的可选 Spotify 歌词来源需要由抽象 `AuthenticationManager` 提供两类 access token，但固定源码没有把这等同于 Client Secret（[AuthenticationManager.swift L3-L13](https://github.com/MxIris-LyricsX-Project/LyricsKit/blob/6f071990d0c9c6f48d29284db805990bffb912ed/Sources/LyricsService/Provider/AuthenticationManager.swift#L3-L13)、[Spotify.swift L13-L29](https://github.com/MxIris-LyricsX-Project/LyricsKit/blob/6f071990d0c9c6f48d29284db805990bffb912ed/Sources/LyricsService/Provider/Services/Spotify.swift#L13-L29)）。

因此可下的 Level B 结论仅是：**该固定 macOS 基础路径不要求 Client Secret**。不能把它外推为 Spotify 所有平台、所有能力或未来 LyricsX 版本都不需要授权。
